# Diabetes Prediction using Machine Learning

## Overview
A machine learning project that predicts diabetes using patient health features and compares multiple classification algorithms.

## Algorithms
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## Workflow
- Data cleaning and missing-value imputation
- Train-test split and feature scaling
- Model training and evaluation
- Comparison using accuracy, precision, recall, and F1-score
- Confusion matrices and feature importance visualization

## Dataset Note
The project uses a dataset that includes synthetically augmented records. These should not be interpreted as independent real patient records.

## Disclaimer
This is an educational machine learning project, not a medical diagnostic tool.
